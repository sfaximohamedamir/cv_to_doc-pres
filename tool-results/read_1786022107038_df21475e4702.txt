     1→# Worklog — Projet Agent de Transformation de CV
     2→
     3→## Vue d'ensemble du projet
     4→
     5→Projet : Agent IA qui transforme un CV (PDF ou image) en document Word ou PowerPoint,
     6→puis attribue un score au CV.
     7→
     8→Modèles NVIDIA utilisés :
     9→- `nvidia/nemotron-3-super-120b-a12b` (modèle texte principal)
    10→- `nvidia/nemotron-3-nano-omni-30b-a3b-reasoning` (modèle omni multimodal pour images/PDF)
    11→
    12→Stack technique :
    13→- Next.js 16 (App Router) + TypeScript
    14→- Tailwind CSS 4 + shadcn/ui
    15→- Prisma (SQLite) pour l'historique
    16→- `docx` pour Word, `pptxgenjs` pour PowerPoint
    17→- `pdf-parse` pour l'extraction texte PDF
    18→- `openai` SDK (API NVIDIA compatible OpenAI)
    19→
